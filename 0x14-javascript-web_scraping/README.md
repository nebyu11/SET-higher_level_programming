# 0x14. JavaScript - Web scraping

## Description
This project covers JavaScript web scraping techniques, manipulating file streams using Node.js `fs` module, interacting with HTTP endpoints using the `request` module, and parsing JSON API responses.

## Learning Objectives
- Understanding JavaScript web scraping concepts.
- Using Node.js `fs` module for file I/O operations (`readFile`, `writeFile`).
- Fetching data from APIs using `request` module.
- Working with asynchronous callbacks and JSON data manipulation.

## File Descriptions

| File | Description |
| --- | --- |
| `0-readme.js` | Reads and prints the content of a file in UTF-8. |
| `1-writeme.js` | Writes a string to a file in UTF-8. |
| `2-statuscode.js` | Displays the status code of a GET request. |
| `3-starwars_title.js` | Prints the title of a Star Wars movie matching a given episode ID. |
| `4-starwars_count.js` | Counts the number of Star Wars movies featuring character "Wedge Antilles". |
| `5-request_store.js` | Fetches webpage contents and writes them to a specified file. |
| `6-completed_tasks.js` | Computes the number of completed tasks per user ID from JSONPlaceholder API. |
| `100-starwars_characters.js` | Prints all character names of a specified Star Wars movie. |
| `101-starwars_characters.js` | Prints all character names of a Star Wars movie in exact list order. |
