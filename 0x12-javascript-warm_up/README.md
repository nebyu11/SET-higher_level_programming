# 0x12. JavaScript - Warm up

## Description
This project introduces fundamental concepts of JavaScript programming using Node.js on Ubuntu 20.04 LTS.

## Requirements
- All files interpreted on Ubuntu 20.04 LTS using node (version 14.x)
- All files end with a new line
- First line of all files is `#!/usr/bin/node`
- `semistandard` compliant (version 16.x.x)
- All files must be executable

## Tasks

| File | Description |
| --- | --- |
| `0-javascript_is_amazing.js` | Script that prints "JavaScript is amazing" |
| `1-multi_languages.js` | Script that prints 3 lines: "C is fun", "Python is cool", "JavaScript is amazing" |
| `2-arguments.js` | Script that prints a message depending on the number of arguments passed |
| `3-value_argument.js` | Script that prints the first argument passed to it without using `.length` |
| `4-concat.js` | Script that prints two arguments passed to it in format: `arg1 is arg2` |
| `5-to_integer.js` | Script that prints `My number: <first argument converted in integer>` |
| `6-multi_languages_loop.js` | Script that prints 3 lines using an array of strings and a loop (no `if/else`, only 1 `console.log`) |
| `7-multi_c.js` | Script that prints `x` times "C is fun" (max 2 `console.log`) |
| `8-square.js` | Script that prints a square of size `x` using character `X` |
| `9-add.js` | Script that prints the addition of 2 integers |
| `10-factorial.js` | Script that computes and prints a factorial recursively |
| `11-second_biggest.js` | Script that searches the second biggest integer in argument list |
| `12-object.js` | Script that updates an object's integer property value |
| `13-add.js` | Function that returns the addition of 2 integers |
