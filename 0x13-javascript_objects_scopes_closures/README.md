# 0x13. JavaScript - Objects, Scopes and Closures

## Description
This directory contains JavaScript projects focusing on Object-Oriented Programming (OOP) principles, scopes, closures, inheritance, prototypes, and module exports in Node.js (version 14.x).

## Tasks Overview

| File | Description |
| :--- | :--- |
| `0-rectangle.js` | Defines an empty class `Rectangle`. |
| `1-rectangle.js` | Defines a class `Rectangle` initializing `width` and `height`. |
| `2-rectangle.js` | Defines a class `Rectangle` validating positive integer dimensions. |
| `3-rectangle.js` | Adds `print()` method to print the rectangle using character `X`. |
| `4-rectangle.js` | Adds `rotate()` and `double()` instance methods. |
| `5-square.js` | Defines a class `Square` extending `Rectangle`. |
| `6-square.js` | Defines a class `Square` adding `charPrint(c)` instance method. |
| `7-occurrences.js` | Exports `nbOccurences` to count element occurrences in a list. |
| `8-esrever.js` | Exports `esrever` to reverse a list without built-in `reverse()`. |
| `9-logme.js` | Exports `logMe` printing call count and current argument. |
| `10-converter.js` | Exports `converter` to convert base-10 numbers to any base. |
| `100-map.js` | Imports list and creates a new array multiplying elements by index using `map`. |
| `101-sorted.js` | Imports dict of occurrences and outputs user IDs grouped by occurrence count. |
| `102-concat.js` | Concatenates two source files into a target destination file. |

## Requirements
- Node.js version 14.x / ES6 standard
- Code style: `semistandard` compliant (Standard + semicolons)
- First line of all executable files: `#!/usr/bin/node`
